Add a validated operational planning model and transactional store with FS
dependencies, precedence-based critical path, capacity conflicts, forward
rescheduling, bounded undo/redo, and versioned JSON import/export.

typed controller events, reliable plugin cleanup, stable keyboard focus,
geometry-aware picking, accessible chart tooltips, and GPU context-loss recovery.

D3 hierarchies and Sankey layouts. Include bundled third-party notices and package
licenses. Invalid options/data previously ignored now produce explicit errors;
consult docs/MIGRATION-TECHNICAL-CONFIDENCE.md before upgrading.
